# 👨‍💻 Página Pessoal — Ronaldo Mello

Projeto de uma página pessoal desenvolvida para apresentar meu perfil profissional, projetos e principais links em um único lugar.

A proposta foi criar uma interface moderna, responsiva e com uma identidade visual inspirada no universo **Matrix**, utilizando efeitos visuais e animações para tornar a experiência mais dinâmica.

## 🚀 Tecnologias utilizadas

* ``**HTML5**`` — Estrutura semântica da página
* ``**CSS3**`` — Estilização, responsividade, animações e efeitos visuais
* ``**JavaScript**`` — Interações e comportamentos dinâmicos
* ``**Vercel**`` — Hospedagem e deploy do projeto

## 🛠️ Técnicas utilizadas

* Design responsivo para diferentes tamanhos de tela
* Layout com **Flexbox**
* Variáveis CSS para organização dos estilos
* Animações e transições com ``**CSS**``
* Efeitos visuais inspirados no ``estilo Matrix``
* Organização semântica do HTML
* Links e botões interativos
* Estrutura otimizada para dispositivos móveis
* Separação e organização de ``HTML, CSS e JavaScript``

## 🎯 ``_Objetivo_``

Criar uma página simples e profissional para centralizar minha presença digital e demonstrar minhas habilidades no desenvolvimento web.
